# Фотографии сайта

Положите файлы сюда с этими именами — сайт подхватит их автоматически
(после перезапуска `npm run dev` / при `npm run build`):

| Файл | Где на сайте | Что снять |
|---|---|---|
| hero.jpg | первый экран | зона ремонта с автомобилем на подъёмнике или фасад с вывеской |
| workshop.jpg | «Что вы получаете» | цех, оборудование, механики за работой |
| services/maintenance.jpg | главная популярная услуга | механик за работой, крупный план |
| cases/*.jpg | «Работы» | реальные выполненные работы: деталь до/после, автомобиль на подъёмнике |
| og.jpg | превью в соцсетях | 1200×630, фасад или цех |

Горизонтальные фото, от 1600px по длинной стороне, JPG до 500 КБ.
Если файла нет — вместо него показывается аккуратная заглушка, а не битая картинка.

## Демо-фотографии в шаблоне

Фото, которые лежат здесь сейчас, — иллюстративные материалы для демонстрации шаблона. Это не снимки конкретного автосервиса. Перед публикацией сайта клиента замените их на его собственные фото (имена файлов те же).
`cases/sportage-2.jpg` — крупный план передней части Kia из `cases/sportage-1.jpg` (отдельный кадр для галереи кейса). Для реального сервиса лучше заменить его настоящим фото тормозного узла.
